# OSRS Path 2.82.0

- v14 adaptive planner: one live Decision, computed from your character, now drives Path, Skills, Gear, Shopping, Money, the maps and the RuneLite HUD. The old per-screen next-step selectors are retired.
- Money: when a step needs coins, the planner compares earning now with training a skill first that unlocks a faster method, and times gathering quest items yourself.
- Fights: the wiki enemy reader now reads every stat field, so Delrith and the right Brutus versions are estimated; dangerous steps you can run past no longer demand a won fight.
- Preparation picks a bank by walking time, not straight-line distance.
- Path: pressing Done when the planner has no answer opens the next open step instead of stalling. Rune shortsword icon fixed.
- Speed: updates within +3% and start-up within +7% of 2.81.42; one planner decision takes about 66 ms (95th percentile).
- Live in-game acceptance of this release is still pending.
