# OSRS Path 2.81.0

- New desktop look, Concept A "The Adventurer's Ledger": a title strip, a HUD with the character, game mode, quest points and the RuneLite link, a spine of sections and an open book. Every section is a two-page spread.
- Journey (Path): the route is a road of stages on the left page; the step is on the right page with its readiness plaque, the current action and ribbons for Steps, Preparation, Route & game, Details and the pinned Wiki dossier. P, T and D switch ribbons.
- A hotbar under the book holds the step actions: Previous (Q), Fix (F), Start the step (S), Show in game (G), Done, World map (M), Skip step, Remove mark (U), Next (E).
- Skills, Journal, Loadout (Gear), Provisions (Shopping), Coffers (Money), Lore (Reference) and Settings keep all their controls. Search and dialogs use the same parchment style. Cinzel and EB Garamond are bundled, so the app stays offline-capable.
- The layout is 1:1, so interface scale, text size and Windows display scaling work as before. Light/System theme does not change the Ledger's single palette.
- No route data, progress format, readiness logic, bridge protocol or overlay changed; the plugin version string is synchronized. Live RuneLite acceptance of this look is not claimed here.
