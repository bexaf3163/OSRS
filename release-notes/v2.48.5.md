# OSRS Path 2.48.5 — Modern Path

- A quieter charcoal desktop interface with compact sidebar navigation, soft accent colors and one prominent current action.
- Preparation, walkthrough, travel and details open on demand. The full route opens from All stages. Critical step warnings and recovery stay visible; all existing completion, profile, shopping and navigation controls remain accessible.
- Quest instructions now follow the plugin's confirmed quest cursor independently of a temporary arrow destination. A later quest stage can no longer be presented as its first NPC merely because the arrow points there. Older plugins explicitly identify navigation targets instead of claiming confirmed quest progress.
- Shopping adapts to the space available beside the app sidebar. Light/system themes, text scaling, Classic style and compact mode remain supported.

Update through Settings → App to keep the existing portable data directory, then restart RuneLite through OSRS Path so it loads plugin 2.48.5. The existing bridge protocol remains 6.
