**Переработка игрового аддона: список «Что нужно» знает этап квеста.**

- **Этапы квестов в игре.** Плагин читает переменную квеста (номера из Quest Helper) и показывает только текущий этап: «Этап 4 из 7», его шаги по порядку, предметы именно этого этапа и одну точку. Текущий шаг переходит сам, когда подходишь к месту следующего, или кликом по строке (кнопка «шаг сделан»). Стрелка ведёт к текущему шагу. Квест сдан — «Квест пройден», проверка вылета очищается.
- **Полные маршруты из Quest Helper.** 32 квеста пересобраны по режиму full assistance: Knight's Sword теперь содержит «поговорить со Squire», подъём по лестнице и обыск шкафа; Prince Ali Rescue — ключ по оттиску на печи, а не у Osman. Маршрут шага (раздел «Прохождение») строится из того же источника.
- **Вид.** Плашки в игре — тёмная скруглённая карточка с цветной полоской (золото — обычно, зелёный — готово, красный — опасность), полоски прогресса этапа, проверки вылета и оптового списка; подсветка строки со скруглением.
- **Приложение.** Выпадающие списки в стиле программы; «Как добраться» — название и статус не налезают друг на друга; «Проверка вылета» после сдачи квеста пишет «Шаг выполнен», а не «не хватает предметов».

**Не проверено в живой игре:** значения переменных квестов на живом персонаже, переход шага по месту, стрелка за шагом, новый вид плашек.

**Проверки:** тесты программы, тесты плагина, интерфейс в браузере, проверка данных, совместимость с RuneLite.
