# OSRS Path 2.80.12

RuneLite started from OSRS Path now gets a 1024 MB Java heap instead of 768 MB.

- The 768 MB heap leaves little headroom with 117 HD, Quest Helper and Shortest Path loaded, and garbage collection pressure can show as stutter in busy areas such as the Grand Exchange.
- The other Java arguments are unchanged, and RuneLite's own launcher settings are not touched.
