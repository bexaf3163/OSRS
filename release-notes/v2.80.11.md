# OSRS Path 2.80.11

An ordinary edit no longer overwrites a desktop save changed outside the running app.

- The shared writer checks the last-read file before changing its primary or session backup.
- Working edits remain in browser storage. The existing warning explains how to export them and reload.
- Reload retains the external bytes in a separate recovery file before normal saving resumes. If that copy fails, the source stays protected.
- The same protection covers progress files and the character list; successful writes update the known revision.

Existing save formats and UI controls remain unchanged. This detects changes visible before writing; it does not add external file watching, automatic merging or cross-process locking.
