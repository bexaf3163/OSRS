# OSRS Path 2.82.3

- Skills goals come from the planner. The Skills page, the "Now by the plan" row, the combat range hints and the calculator's default target use the levels the planner's Decision needs, with the reason ("The planner needs Attack 30: ..."). When it needs none, the page says so and shows the end of the current training row. The old guide's chapter goals and "Stage N goal reached" notes are gone.
- Shopping plans for "Stock up" (the step and the planner's next steps) or "This step". The "Stages" scope, which bought for the old guide's chapters, is removed.
- The RuneLite bank highlight marks the items of the step in the game and the planner's next steps, instead of every item of the old guide's chapter.
- Removed the unused stage helpers and their styles.
- Live in-game acceptance of this release is still pending.
