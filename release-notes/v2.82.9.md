# OSRS Path 2.82.9

- Steps that train skills no longer list rows from the old training table. The step's Preparation tab shows the training engine's card for one skill, as before, and now gives every other open skill of the step one line from the same engine: "Cooking to 68: Cook Salmon — Barbarian Village fire, then Wine (a jug with grapes) from 35 · about 2.4 h–3.7 h". The skill name links to its page with the full card.
- Combat steps that are their own method (Minotaurs, Hill Giants) no longer show table monsters that contradicted the step's own opponents.
- Skills without a training method in the engine yet (for example Slayer) say so on that line.
- Live in-game acceptance of this release is still pending.
