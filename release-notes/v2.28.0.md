**OSRS Path is now fully in English: the program, the RuneLite plugin, the route data and the documentation.**

The wording follows the OSRS Wiki and Quest Helper: item, NPC, quest and place names are the in-game ones, and the step texts, dialogue options and menu actions match what the game shows. No Russian is left anywhere in the project, and no name is given twice any more (the old "Russian name (English Name)" pairs are gone).

**What changed**

- The whole interface: all screens, the header, the settings, the reference, the search, the step cards, the readiness and preparation blocks, the map and the messages. Numbers use English formatting (`2,000 gp`, `12.3 kg`), and plurals follow English rules ("1 item", "3 items").
- The RuneLite plugin: the HUD, the "What you need" list, the side panel, the exchange hint, the radar and pace lines, the settings names and descriptions, the chat messages and the debug journal. The plugin settings keep their keys, so everything you configured is kept.
- The route data: the 69 steps, the 32 quests' stage lines, the training methods, the earning methods, the gear and monster data, the transport guide and the reference. Quest stage lines keep their Quest Helper step keys, so the Quest Helper machines work exactly as before.
- The plate texts in the game are drawn in one font per line, so letters, digits and symbols no longer come out in different sizes; the stage list on the "Path" screen shows long step titles on two lines instead of cutting them off.
- Your progress, notes, profiles and the data folder are untouched. A main profile that an older version named in Russian is shown as "Main". The auto-update keeps working: the file is still `OSRS-Put-<version>-portable.exe`, the data folder is still `OSRS-Put-data`.

**Cleaned up**

- Removed the leftover Russian-name fields from the data and the types, the old guide pipeline, obsolete reports, unused functions and exports (`getBridgeStatus`, `getPlayerStats`, `searchWiki`, `searchLocalItems`, `lineKey`, `setActiveStepId` and a few more), unused styles and old documentation.
- The documentation is rewritten in English: `README.md`, `PROJECT_MAP.md` (replaces the Russian-named map), `PROJECT_GUIDELINES.md`, `tools/qh-machines/README.md`.
- The data checks were adapted to the English texts, and the telemetry report now says "1 error" and "2 errors" correctly.

**Checked**

- 616 app tests, 329 plugin tests, `check-data` (0 errors, 0 warnings), the production build and the browser interface checks (97 pages at two widths, the header at ten widths) all pass. The readiness snapshot of all 69 steps in six scenarios gives exactly the same statuses as before; only the wording of labels changed.
- The in-game text layout test draws the HUD, the list, the bank, the exchange and the shop windows with the real RuneLite fonts for every step and finds nothing outside the frames.

**Not checked in the live game.** This version was not run in the game: restart RuneLite after updating so that it loads the new plugin, and if a line looks wrong or cut off, send a screenshot or the debug journal.
