**A new calmer look: frosted glass panels, a readiness ring on the step status, and a chip summary in "What you need".**

- **Glass look (default):** rounder panels with a soft frosted blur, a gentle glow by state (green ready, gold preparing, red blocked) instead of the hard left strip, and the current stage and step glow gold as "in progress". Works in the light and the dark theme.
- **Readiness ring:** the step status now shows the readiness percent as a ring in the state colour, next to the same status text and buttons as before.
- **Chip summary:** "What you need" opens with chips grouped by timing (Take now, Meanwhile, Along the way, Do not take now). Each chip says where the item is in words: in the bank, missing, or not checked. Unchecked items are never shown as missing. The full list with the buy and take actions stays right below.
- **Settings, Look tab:** a Look switch (Glass or Classic) brings back the previous flat look in one click, and "Solid panels" turns the blur off for weak graphics. Both are remembered.
- **Build fix:** the page security hash is now computed on the same line endings the browser uses, so a copy of the project with Windows line endings can no longer block the page script.

No data, saves or game-plugin behaviour changed.

**Checked.** App tests (630), data checks, the production build and the browser interface checks pass. Not run in the live game: this release does not change the in-game overlays. They get the matching glass style in the next step.
