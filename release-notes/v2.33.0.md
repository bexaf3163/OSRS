**Old versions of the program no longer pile up: the app keeps only the file with its own version.**

- **Cleanup at start:** when the portable app starts from `OSRS-Put-<version>-portable.exe`, it deletes every older `OSRS-Put-x.y.z-portable.exe` next to it. This covers a manual update, a skipped version, and an in-app update whose cleanup could not finish. A file that is still busy is retried for about 30 seconds.
- **Safe by design:** only files with exactly that name, in the same folder, older than the running version, and never the running file. If you renamed the exe, or it is not the portable build, nothing is deleted. The progress folder `OSRS-Put-data` is never touched.
- **Version in the window title:** the window now says "OSRS Path 2.33.0", so you can see which version is running.
- The in-app update still downloads the new file as `OSRS-Put-<new version>-portable.exe`, starts it, and the old one is removed.

**Checked.** App tests (updater tests for the sweep included), data checks, the production build, the browser interface checks and all plugin tests pass. Not run: a real update on the PC, and the Electron window itself (the title change is in the main process).
