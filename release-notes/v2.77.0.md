# OSRS Path 2.77.0

- **No rule is tied to one step any more.** Every special case that named a route step is now a general rule that reads the step's own data, so a new quest, monster or training step gets every earlier fix with no code change:
  - **Dragonfire:** the "no Anti-dragon shield" block follows the opponent (any fight whose attack the wiki labels dragonfire), not the Elvarg step. A dragon step without a shield in its items fails the tests.
  - **Grand Exchange first:** any step that takes place by the exchange buys there first and in bulk, not only the two Varrock shopping steps.
  - **Quest items to drop:** "its quest is done" is read by the quest's name, not by a step code.
  - **Free items:** the Anti-dragon shield's giver is found by the NPC (Duke Horacio), wherever the route visits him.
  - **Fairy rings:** which step opens them is in the travel data and checked against the route.
  - **Coins for an upgrade:** the tip names the open step of the current stage that pays the most coins (the Stronghold of Security in stage 1), for every stage.
  - **Demon Slayer:** the incantation hint follows the quest stage, not a step code.
- **One reader for quest steps and rewards** across the app. Two rewards written as "2 500 Coins" were read as 500; the data is fixed, and the data check now rejects that format.
- **A guard test** fails if a step code is ever written into the logic again.

No gameplay automation. Saves, route IDs and progress are unchanged.
