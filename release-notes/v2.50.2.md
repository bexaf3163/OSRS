# OSRS Path 2.50.2 — alignment, Skills list, new app icon, Reference out of the menu

- **Alignment on Path.** The "Ready to set off" row had no side padding (the dot touched the border) and the Preparation / Travel / Details buttons were indented from the action's left edge. Both now start at the same edge as the action and the "Show in game" button.
- **Skills list at the side.** On a wide window the skills are a vertical list beside the cards (it scrolls on its own); on a narrower window they wrap into rows. No more sideways scrolling.
- **New app icon.** The window, taskbar and exe icon is the compass from the top of the sidebar (was an old line-chart icon).
- **Reference is not in the menu any more** (sidebar and bottom bar). The pages still open from links inside steps and from search ("Teleports, canoes and boats", "RuneLite plugins", "If you are stuck"); only the menu entry is gone.

Presentation only; the data, the preparation engine and the game guide are unchanged.

**Checked:** build, TypeScript tests, data consistency, the full Java suite, the production UI run, screenshots of the real build. Not checked in the live game.

Restart RuneLite through OSRS Path after updating.
