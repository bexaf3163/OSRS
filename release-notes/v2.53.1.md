# OSRS Path 2.53.1 — Shield of Arrav: the book moves the card on

- **Shield of Arrav:** with the book in your bag the card kept saying "Search the bookcase and read the book". It is two lines now: search the marked bookcase (done when the Book is in the bag), then read the book in your inventory; the quest moves on once it is read.
- **A check of every quest for the same mistake:** a line that fetches an item and uses it in one sentence. Shield of Arrav was the only one; a new test fails if another appears. The item names added in 2.53.0 were checked against the game's names (Book, Weapon store key, Intel report, Broken shield, Phoenix crossbow, Certificate, Poisoned fish food, Dirty blast).
- **Route file:** `docs/route-export.md` can be rebuilt with `node scripts/export-route.mjs`.
- **Checked:** `tsc`, build, 969 Vitest tests, `check-data`, the full Java suite (486, new: `ShieldOfArravStageTest`).
