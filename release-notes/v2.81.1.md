# OSRS Path 2.81.1

Fixes to the Ledger desktop after the first look in the real window.

- Skills: each tile shows the glyph, name and level on one row and the F2P checkpoint under them; the checkpoint no longer covers the level.
- One type everywhere: the RuneLite link in the header, the Launch RuneLite button, the Wiki dossier, dialogs, levels and step codes now use the Ledger's EB Garamond and Cinzel instead of Inter or the system monospace.
- The spine names match the pages it opens: Journey, Skills, Journal, Gear, Shopping, Money. Reference is no longer in the spine; it stays reachable from Search, the step's reference links and its own address.
- The header no longer has the Zen and Inspect buttons. Compact stays; the Zen/Inspector density is still in Settings → Appearance.
- The hotbar slot F is called Preparation (with a bag icon) when it opens the Preparation ribbon, and Fix only when it leads to what is missing.
- Show in game and Start the step report "RuneLite is offline. Target saved." or the profile message when RuneLite cannot take the target, instead of doing nothing silently.
- World map (M) opens the map every time it is pressed; the map no longer reopens by itself when the Route & game ribbon is visited again.
- A complete chapter on the road unrolls with Unroll and folds back by clicking its heading.
- A new desktop scenario clicks every spine link, header control, road control, ribbon, hotbar slot and the Journal, Reference, Settings, Skills and Shopping menus and checks the result.
