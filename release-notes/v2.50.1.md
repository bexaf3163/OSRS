# OSRS Path 2.50.1 — Path layout polish

Fixes from the first look at 2.50.0 on a wide window.

- **No empty middle column.** A step with nothing to bring (Shield of Arrav, most travel steps) used to leave a lone "Ready to set off" box floating in a wide empty column. The verdict is now a slim row under the action and the walkthrough takes the freed width.
- **One "ready" signal.** The ring and a green dot after it said the same thing; the dot is gone where the ring is shown.
- **Search bar.** The top bar is a search field (press / anywhere) with the connection state and Settings on the right, instead of an empty bar with a "Path" label.
- **Game mode is a labelled control.** "F2P" under the logo is now "Game mode  F2P ▾", a visible dropdown rather than a bare word.

Presentation only; the data, the preparation engine and the game guide are unchanged.

**Checked:** build, TypeScript tests, data consistency, the full Java suite, the production UI run, screenshots of the real build at 1910 px.

Restart RuneLite through OSRS Path after updating.
