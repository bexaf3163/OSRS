# OSRS Path 2.63.3

- **"Launch RuneLite" in the header.** A button at the top of every page starts RuneLite with the plugin (the same launch as in Settings →
  RuneLite). It shows while the plugin does not answer, says "Starting…" for about ten seconds after a click, and leaves once RuneLite is
  connected. On a narrow window only the controller icon stays.
- **The direction arrow in the game's guide panel now points the way you see it.** "~15 tiles ↘" was a compass direction (up is north), so it
  disagreed with the big arrow in the world, which turns with the camera. The glyph is now turned by the camera the same way, so "↑" means
  ahead of the camera. It follows the camera at the next game tick.
