# OSRS Path 2.90.0

- Quest fights for a bow user: with a bow worn, the fight estimate shoots rapid with your worn arrows at your Ranged level, using the bow's, arrows' and ranged armour's bonuses (the same model as Ranged training). The opponent's hits, the food and fight mechanics such as Count Draynor's regeneration are estimated as before. Before, every fight asked you to "Review the combat strategy" while you held a bow. With no arrows worn, or your Ranged level not yet read, the fight stays unestimated.
- The fight preparation the planner compares is still melee: for a bow user it can keep your bow when that is already safe, but it does not yet propose Ranged training or ranged kit.

Verified before delivery: 2,641 unit tests, the route gate (23 of 23 quests, no check, 51 turns with an unknown time) and 769 browser checks; typecheck/build, data/fixtures, structure, unused-code and dead-CSS gates. The plugin code is unchanged since 2.87.0 (its 640 tests passed then). Paired timing against 2.89.1: mean non-XP update script time +3% (13.8 → 14.2 ms), cold-start script time lower on every measured page. Native Electron checks and the isolated Portable EXE run in the release workflow. No real-game testing is claimed.
