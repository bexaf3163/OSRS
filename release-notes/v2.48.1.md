**Demon Slayer moves on when you hold Silverlight; no "leave the armour in the bank" before a fight.**

- **S3-03 (Demon Slayer):** once Sir Prysin handed over Silverlight the list stayed on "Give Sir Prysin the three keys" until you walked to the stone circle. The Quest Helper machine ended in an unresolved step because the kill step is wrapped in the helper `IncantationStep`, which the generator did not see through. The wrapped step is now the default, so with Silverlight in the bag or the bank the list goes to "Kill Delrith with Silverlight". Fixed in the generator (`tools/qh-machines/qhm/interp.py`) and in `src/data/questMachines.json`; it was the only unresolved node in all 32 machines, and a test now keeps it that way.
- **Weight advice:** the "Leave the extra in the bank" card looked only at the step's own foe list, and a quest step has none, so it could ask you to deposit your armour before a fight at the end (Demon Slayer) or in the middle (Draynor Manor, the Black demon, Melzar's Maze) of the quest. A quest chain now counts as combat when any of its lines names a fight (dialogue choices are not read), and so does any step of the same trip. When in doubt there is no advice, as before.
- **Checked:** 893 Vitest tests (new: `QhDemonSlayerTest` in Java, the machine-data and weight cases in `tests/questMachines.test.ts` and `tests/weight.test.ts`), `check-data`, the full Java suite. The Quest Helper generator itself was **not** re-run (no Python on this machine); the JSON edit mirrors what the patched generator emits for that node, so run `build_machines.py --check` on a machine with Python. Not confirmed in the live game.
