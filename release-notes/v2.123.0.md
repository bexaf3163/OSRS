# OSRS Path 2.123.0

- In Members mode the Skills page shows one grid of all 23 skills, in the in-game skill tab's order, including Hitpoints, which was missing before. The separate "Members skills" block and its purple tile border are gone, so every skill looks the same.
- Every Members tile now has a status line like the free-to-play tiles. The line names the highest level an unfinished route quest needs, for example "→ 43 for quests", "✓ 25 for quests" or "· No quest needs it". It uses the same font, size and place as the free-to-play line.

Verified before delivery: 2,647 unit tests, the browser and Electron desktop checks (a new check counts 23 tiles and 23 status lines in Members mode), the plugin tests, typecheck/build, data/fixtures, structure, unused-code and dead-CSS gates, and the route gates in CI. Nothing was tested in the real game.
