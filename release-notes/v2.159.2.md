# OSRS Path 2.159.2

Members planning is about twice as fast while you gather. Before, every new log, ore or fish made the planner rebuild every skill's training forecast, which took about 2.5 seconds each time early in the Members route. Now it rebuilds only the skills that use that item, so the same update takes about 1 second.

The planner also works out the training needed to win each quest fight once per decision instead of once per projected quest, and it no longer filters the whole gear list again for every melee method.

Releases are faster. The route gate replays the Members route in 5 parts at the same time, each from a saved checkpoint, so CI no longer waits about 18 minutes for one long replay. The gate now also reports how long each planning decision takes, because the app runs the same decision on every game update.

The skill plan check now also fails a free-to-play plan with no time estimate, a stage below its method's level, or a Members method in a free-to-play plan.

Verified before delivery: the unit tests, the route gate (all 23 free-to-play quests and all 132 Members-route quests, with every reused forecast recomputed and compared), the browser checks, the Electron desktop checks, the plugin tests, typecheck/build, structure, unused-code and dead-CSS gates. Nothing was tested in the real game.
