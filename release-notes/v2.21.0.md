**Шаг этапа больше не теряется: руда засчитывается сама, «сделано» не прыгает мимо сдачи, есть «Назад»; верхняя плашка в игре убрана, тексты — короткие.**

Случай, с которого всё началось (The Knight’s Sword): руду добыл — шаг не засчитался; прощёлкал «сделано» мимо сдачи руды Thurgo, оказался на «Отнеси меч Squire» с рудой в сумке и не понимал, на каком он шаге и как вернуться. Это была не одна ошибка, а целый класс: шаг считался один раз вперёд, по клику и по месту, без памяти и без пути назад. Теперь курсор шага считается по состоянию каждый тик.

**Как шаг определяется теперь**
- **Добыл — засчитано.** У шагов «накопай / возьми / сорви / купи X» есть условие «X в сумке»: оно стоит у всех 15 таких шагов (раньше было у части). Шаги перед ним без условий («спустись в пещеру») засчитываются вместе с ним — руда есть, значит, в пещере был. Через шаги с предметами не перепрыгиваем: предметы можно собирать в любом порядке. Проверка данных теперь ловит такой шаг без условия (правило `stages-has-missing`).
- **Сдал — засчитано.** Шаг «верни X NPC» сдан, когда X, что был в сумке, ушёл рядом с точкой шага (в пределах 12 клеток) — в том числе одна руда из двух. Предмет, пропавший далеко (выбросил, потерял), сдачей не считается.
- **Не сдал — дальше не уйдёшь.** Пока X в сумке, курсор не уходит за шаг «верни X» — ни по клику, ни по положению. Игрок у Squire с рудой в сумке — список возвращает его к Thurgo и пишет почему: «⚠ Blurite ore ещё в сумке — сначала: Верни Thurgo…».
- **Клик «шаг сделан» на несданном шаге** сначала предупреждает, второй клик подтверждает: человек знает лучше (предмет мог остаться в сумке по другой причине).
- **«◀ Назад: …»** — кнопка под текущим шагом, если он не первый. Возвращает шаг и держит его «вручную»: автоматика не уносит курсор вперёд, пока снова не нажато «сделано» (в строке шага — «вручную · 2/4»).
- **Где ты:** справа от текущего шага «3/4»; в заголовке — код шага: «S2-07 · Этап 7 из 7».

**Что убрано из игры**
- **Верхняя плашка (HUD)** — «К месту: …», «Потом — шаг …», «~165 клеток», «Сумка готова к выходу» — рядом со списком «Что нужно» дублировала его, стрелку и миникарту. Теперь она показывается, только когда есть что сказать: опасность, здоровье, действие («Use X на Y»), темп, совет по снаряжению. Нет списка (свёрнут, выключен, шаг без него) — HUD остаётся как был, только без «Сумка готова». Настройка «Компактный HUD» (по умолчанию включена); выключишь — как раньше.
- **Блок «Нужно сейчас» на этапе** показывает только то, чего ещё нет с собой. Всё взято и сдано — блока нет, зелёных галочек нет.
- **«Куда идти» на этапе из нескольких шагов** не показывается, когда у текущего шага есть клетка: точка этапа в целом («вход в подземелье») к концу этапа устаревала и вводила в заблуждение.

**Тексты короче**
- У каждой строки этапов (644 строки, 505 разных) написан короткий текст (поле `s`, до 70 знаков, без диалога, английские названия предметов, как в игре). В списке — он; полный текст остаётся в подсказке при наведении и в панели «OSRS Путь».
- Серый список «• … • … … ещё шагов: N — в панели справа» заменён одной строкой «Дальше: …» и счётчиком «+N». «Сделано шагов: N» убрано — прогресс виден в «3/4». Остальные «— в панели «OSRS Путь» справа» сокращены до «… ещё N» (полный текст — в подсказке).
- Стрелка к шагу подписывается коротким текстом, а не целым абзацем («К месту: Отнеси меч Squire»).
- Строки без короткого текста (новые шаги, «Дальше» у шагов без этапов) сокращаются сами по тем же правилам в программе и плагине. Проверка данных не пропускает этап без короткого текста или длиннее 72 знаков (правило `stages-short`).

**Не проверено в живой игре:** весь новый вид списка, кнопка «Назад», двойной клик на сдаче, возврат курсора по руде, пропажа плашки HUD. Проверено тестами с теми же данными и теми же координатами, что в S2-07.

**Проверки:** тесты плагина (курсор шага 15, плашка HUD 6, короткий текст 6, список этапа), тесты программы (короткие тексты 7, проверка данных), интерфейс в браузере, проверка данных, совместимость с RuneLite.
