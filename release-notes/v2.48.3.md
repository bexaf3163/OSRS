# OSRS Path 2.48.3 — Clear Path workspaces

The redesign now changes the workspace structure across the app: section sidebars, stacked desktop navigation, a selected quest preview, six equipment slots, training method and location cards, and settings with a live appearance preview. Path keeps its walkthrough beside preparation and rewards; the shopping summary follows the table.

- Native RuneLite quest cards use a quest marker, a stronger current action, a tab strip beneath the action, and the matching dark blue palette. Existing guidance, warnings, mouse actions and font choices remain available.
- Item and skill icons are bundled so the interface remains complete without access to the Wiki image server.
- Existing profiles, progress, manual ownership, preparation, bridge protocol and game controls are preserved.

Download the portable executable and place it alongside the existing portable data folder. Restart RuneLite after updating the bundled bridge plugin.
