# OSRS Path 2.188.4

## The plugin no longer stalls the login

2.188.3 hung while the character loaded. At login the game reports your Grand Exchange offers. The new offer counting asked each offer for its price, a method your RuneLite client does not have, and the error stopped the plugin's login handling. The plugin no longer asks for the price, and any further mismatch in the offer data now drops only the offer count, never the login.

Without the price, a buy offer still counts the items already bought but no longer the coins it holds in reserve. Sell offers count as before: the unsold items and the coins already made.

Verified before delivery: all plugin tests. The app is unchanged since 2.188.3, so its unit tests and route gates ran in CI only. Nothing was tested in the real game.
