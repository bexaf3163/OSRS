**Clear Path: one current action on the Path screen, six sections, a compact view and a calmer in-game guide. No route or engine change.**

- **Path.** The step is a workspace with four tabs: Steps, Preparation, Travel and Details. The route is a rail on a wide window and a "Route" drawer on a narrow one. The status line says one thing: ready, preparation needed, or not checked yet. Steps with no live sub-step say "Starting point" instead of guessing.
- **Compact view.** A switch in the header (and in Settings) shrinks the Path to the current action, its place and three buttons, for a 360-480 px window beside the game. Same state, fewer panels.
- **Six sections.** Path, Skills, Gear, Shopping, Journal (Quests, Goals, Session) and Reference. `#/quests` and `#/goals` still open the Journal tab; nothing was removed.
- **Skills.** Each skill has Overview, Roadmap, Calculator and Reference tabs. A focus line names which skill to train for the current goal (the route goal first, then the next stage goal ahead, then the plan row). On a free account the roadmap opens in F2P Only by default.
- **Gear.** The page is regrouped into Current equipment, Recommended improvements and Future unlocks. Unknown slots read "? Not checked", and a purchase is called "Consider buying" with a note until the game has shown your bank.
- **Shopping.** A table of Item, Required, Owned, To obtain, Source, Estimated cost and Action (stacked below 900 px), with a separate group for items the game has not confirmed. Unverified items are no longer counted as purchases or budget.
- **One link vocabulary.** The header chip, the Settings page and the in-game panel use the same words for the RuneLite link and for the navigation target.
- **Zoom.** Auto-zoom in the desktop app is clamped to 1 to 1.5 of the base width, so a small window is never shrunk below readable.
- **In the game.** The guide plate keeps its 190 px (HUD) and 240 px (Guide) widths. The hover tooltip opens beside the plate and never covers the list. The Steps and Advice tabs have separate click areas. A stage's list is headed "Needed for this stage" and the count reads "Stage items in your bag: N of M"; before, the label could be read as the whole quest. When a pre-flight check blocks the arrow, one line on the plate says what is missing and how to get it (bank, the place, or the Grand Exchange), also when the plate is collapsed.
- **Six consistency fixes**, each with a test: the Reference food advice matches the route (it buys its food); a target saved while offline reads "Target saved. Waiting for RuneLite" instead of looking live; unverified shopping items are not counted as purchases; the melee focus follows the route goal; the roadmap default respects a free account; the item count on a quest stage names its scope.
- **Checked:** the full gate (`npm run build`, 888 Vitest tests, `check-data`, the Java suite) and the UI smoke run on this machine with Edge. Screenshots at 1440, 1280, 1024, 800, 480, 440, 390 and 360 px in both themes were reviewed by eye on a stubbed bridge.
- **Not confirmed:** nothing here was run against a live RuneLite client. The Java overlay layout is covered by pixel-free layout tests and by fake-graphics renders, not by a screenshot from the game.
