# OSRS Path 2.94.1

- The app speaks in one visual style. The remaining colourful emoji are gone. Step status, preparation, gear, the map, Money and the funding line use the Ledger's own line icons (compass, sword, bag, map, target, lock, coin…), the same family as the left rail and the bottom bar. Readiness buttons read "To the bank", "To shopping", "Catch up Crafting", "Earn it: Money" without emoji in front; the arrow button already draws its compass. The "Starting RuneLite…" and "You are there" notices are plain text. Warning signs use the plain ⚠ sign instead of the yellow emoji.
- Nothing changes in the game: the RuneLite card already draws its own icons and drops a leading marker from the app's lines.

Verified before delivery: 2,651 unit tests, the route gate (23 of 23 quests, no check, at most 1 turn with an unknown time), 787 browser checks (the readiness actions are checked by their new wording) and the Electron desktop checks, run locally under a virtual display; typecheck/build, data/fixtures, structure, unused-code and dead-CSS gates. Screens checked by eye: a step's status and preparation, Gear, Money. One paired timing against 2.94.0: mean non-XP update script time +1% (14.1 → 14.3 ms); cold start faster on every measured page (script time −4% to −15%); page switches varied from −37% to +44% in this single pair (the new build ran second, which is known to read slower), with no code change on those paths beyond text. The plugin code is unchanged since 2.87.0 (its 640 tests passed then). Nothing was tested in the real game.
