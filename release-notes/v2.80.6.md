# OSRS Path 2.80.6

More trustworthy food replacement advice.

- Cheaper food comparisons use healing the character can actually receive at their Hitpoints level. At10Hitpoints, replacing25Salmon requires25Tuna, rather than the previous23.
- Savings inherit the weaker confidence of both purchase quotes. Stale or uncertain prices no longer produce a HIGH-confidence replacement recommendation.

Uses the existing funding and healing systems. No additional menus, automatic purchases or changes to saved progression. Includes the combat supply and bank-certainty repairs from2.80.5.

Normal portable Windows release with the bundled RuneLite bridge, published only after all automated release gates. Live-game acceptance and broader food/packing/acquisition work remain tracked in the attached Claude handoff.
