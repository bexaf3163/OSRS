# OSRS Path 2.80.18

Selecting a skill now opens one compact recommendation instead of a stack of folded explanations. Train shows the method, location, estimates, priority and required preparation; Plan contains method analysis, alternatives and the leveling roadmap. Calculator and Reference retain the existing tools, manual levels, F2P evidence and training reference.

- Balanced remains the default for profiles without an explicit preference. XP/Money choices and adopted plans retain their existing behaviour.
- Missing supplies, unread bank stock, funding shortfalls and model warnings remain visible. Unknown rates/costs are labelled; loot is not described as net profit.
- No route order, completion targets, player saves, model formulas, bridge protocol or launcher arguments changed. Route-step cards retain their original disclosures.
- Existing coverage remains partial: all 23 skills have guides, but several Members skills and some methods still lack personalized models. See `docs/SKILLS_COVERAGE.md`. Live-game acceptance remains with Claude.

Automated acceptance covers direct skill navigation, compact/default and analysis presentations, all available skill tiles at desktop text scaling, retained controls and shared-engine regressions. Publication requires the existing full app, Java, desktop, native and isolated portable gates.
