# OSRS Path 2.48.8 — Consistent game-guide typography

The modern Glass guide now uses the same bundled **Inter** typeface as the desktop instead of inheriting RuneLite's selected game font. Ordinary text, metadata, tabs, the action and hover explanations share one family, with restrained 14/13/16 sizes and the existing large-text scaling.

Text is antialiased and drawn without the inherited game-text shadow. Icon glyphs that Inter lacks use a fallback only for the glyph; entire sentences no longer change typeface. Measurement and painting share those glyph advances, keeping navigation controls aligned.

The font and its SIL Open Font License ship inside the plugin JAR; no system font installation or network font download is needed. Classic mode retains the selected RuneLite font. Disclosure behavior, warnings, quest instructions, navigation, readiness, progress and saved card position/width are preserved.

Restart RuneLite through OSRS Path after updating to load the new typeface.
