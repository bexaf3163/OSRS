# OSRS Path 2.94.3

- XP, Balanced and Money on a skill card now change the training method only. Before, pressing XP also switched the whole app to a hidden "efficient" mode: preparation looked four steps ahead instead of two, announced every next task, listed items needed only later and opened the preparation's "what next" by itself. Now everyone gets the same calm preparation: the current step and the next two (the Shopping list's next trip uses the same two; it looked three ahead before), no extra announcements. The training time estimate on the skill card is shown for everyone (before, only after pressing XP).
- The old "Relaxed" training choice, which had no button since 2.93, is gone: a save that still had it reads as Balanced, and a training plan you followed in its low-effort lane continues as a normal one.
- Money: a new account cannot sell some items on the Grand Exchange until it has 10 quest points, total level 100 and 20 hours of play. The game shows the first two but never the hours, so once both numbers were reached, the guide kept those sales "not confirmed" forever. A single line on the Money page now asks once: "My trade limits are lifted". Undo takes it back. Accounts below the numbers see nothing.
- The welcome card for a new player links the two beginner sections of the Reference: "Signing in and setup" and "If you do not know what to do".
- Removed code the app never ran: a Magic spending plan (cheapest spells to a level, when a staff pays for itself), a gathering time-to-goal estimate and a "reachable quest points" count. The training engine, the live XP rate and the quest point ring already cover them.
- Correction to the 2.94.2 audit: cancelling an update download is not a leftover. The update notice at the top shows "Cancel" while a download runs, and it stays.

Verified before delivery: 2,618 unit tests (14 fewer: those of the removed plans; tests that ran the retired Relaxed ranking now check the Balanced path the app uses), the route gate (23 of 23 quests, no check, 1 of 211 turns with an unknown time), 797 browser checks (new: the trade-limits line asks, records and undoes, and stays away below 10 quest points; the welcome card links the Reference; the skill card shows a time estimate on Balanced) and the Electron desktop checks, run locally under a virtual display; typecheck/build, data/fixtures, structure, unused-code and dead-CSS gates. Two paired timings against 2.94.2, in both orders: mean non-XP update script time −3% (11.2 → 10.9 ms); cold start +3% on Path, +4% on Shopping, +10% on the Ranged skill page; switching to Skills +18% and to the Ranged page +22% (in both orders). A CPU profile of that switch on unminified builds (6 switches, twice per build) shows no increase (2.94.3: 41 and 36 ms; 2.94.2: 41 and 43 ms), so the timing difference is not traced to a code path. The plugin code is unchanged since 2.87.0 (its 640 tests passed then). Nothing was tested in the real game.
