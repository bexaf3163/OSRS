# OSRS Path 2.94.2

- Skills, free-to-play: Melee combat opens on the skill that still has a checkpoint ahead. Before: it opened on the lowest skill even when that one was past its checkpoint, and the header read "Defence 20 → Goal 10", a goal below the current level. Now, with Defence past its checkpoint and Attack and Strength not, it opens on the lower of those two ("Strength 21 → Goal 40"). A skill whose checkpoint is reached shows its level without a goal arrow.
- A full pass over the app removed code it no longer ran: an older funding adapter (the earning planner replaced it), the app's copy of the in-game pace line (the RuneLite card writes it itself), shopping-list helpers that the "Copy the exchange list" button replaced, unused links between modules, a play-style label nobody saw, and a saved-data key for combat plans retired in 2.85.2. The skill page no longer draws a heading only to hide it. Nothing you see changes apart from the Skills fix above.

Verified before delivery: 2,633 unit tests (18 fewer: those of the removed code), the route gate (23 of 23 quests, no check, 1 of 211 turns with an unknown time), 791 browser checks (new: the Melee combat page opens on Strength 21 → Goal 40 with Defence past its checkpoint, and a reached checkpoint shows no goal), the Electron desktop checks run locally under a virtual display; typecheck/build, data/fixtures, structure, unused-code and dead-CSS gates. Two paired timings against 2.94.1, in both orders: mean non-XP update script time unchanged (11.5 → 11.5 ms); cold start −3% on Path, −1% on Shopping, 0% on Ranged; switching to Skills +12% averaged (+24% when the new build ran second, +1% when it ran first; +0.4 ms of script). The plugin code is unchanged since 2.87.0 (its 640 tests passed then). Nothing was tested in the real game.
