# OSRS Path 2.81.37

- Melee training now prepares the same complete kit as Ranged: owned better gear is worn, and with known coins and prices the best affordable amulet and armour for the trainer's opponents are bought (for example an Amulet of strength and Adamant armour at Defence 30). Weapon purchases for every combat style keep going through the one upgrade evaluator, which checks them against the trainer's XP model.
- The training plan forecasts a later stage with the kit the stage recommends for melee too, not only for Ranged.
- Any affordable armour that makes the opponent hit less often is now advised; before, a change under 3 percentage points was left out.
- One opponent table: the gear advice reads the same opponent data as the combat estimate (combatFoes.json, free version first, then the lowest level). The old monsters.json and its separate builder are removed.
