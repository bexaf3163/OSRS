# OSRS Path 2.122.0

- New Members quest: Clock Tower. You collect the four cogs in the tower and its dungeon, and the route runs past the level 53 ogres instead of fighting them. The Members route now finishes 52 of 52 quests.
- Quest Helper steps whose default is set later are now read correctly. Clock Tower's last step had shown as unknown because of this.
- Fewer turns with an unknown time on the Members route: 2 instead of 4. Before, wearing gear that a quest might hand in, such as the amulet of power and the anti-dragon shield before Elvarg, blanked the time of every later training. The planner now times that training without the gear and never reuses it.
- The "Keep Defence at 1" option on the Skills page is removed. A saved choice from an older version is ignored.
- In-game overlay:
  - The guide card's text is 15% larger by default.
  - Alt-dragging the card's width now zooms the whole card, so text, icons and margins grow and shrink together. Before, only the line length changed.

Verified before delivery: 2,644 unit tests, the F2P route gate (23 of 23 quests, 0 unknown turns), the Members route gate (52 of 52 quests, 2 unknown turns), the browser and Electron desktop checks, the plugin tests, typecheck/build, data/fixtures, structure, unused-code and dead-CSS gates. Nothing was tested in the real game.
