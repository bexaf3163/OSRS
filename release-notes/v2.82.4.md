# OSRS Path 2.82.4

- Path shows the planner's order and the chosen step only. The old guide's walkthrough (chapters and their numbered steps) is gone, with its chapter and step-number labels. The step header now says "PLANNER #n OF m", or "NOT IN THE PLANNER'S ORDER" for a step opened by a link.
- No step is ever guessed from the old guide's order. Without a Decision, Path waits for the planner. When the planner's next action has no step of its own (for example "Read Below Ice Mountain in the quest journal"), Path shows that action and its reasons. When it is a level check for a quest, Path opens that quest's first open step.
- Marking a step done no longer jumps to the next guide step when there is no Decision; the planner chooses what comes next.
- The guide's "Better after (optional)" hints are removed from step cards.
- Before its first Decision, the planner ranks money methods at the step the game shows, not the guide's first open step.
- Path starts about 13% faster with 65% less blocking time, and switching to it is about 34% faster.
- Live in-game acceptance of this release is still pending.
