# OSRS Path 2.92.1

- A quest started outside the guide no longer leaves you stuck at "Verify the current stage". For a quest that is a single route step (all F2P quests except Dragon Slayer), the check now points the game at that step, so the plugin reads the quest's stage there and the plan continues by itself. Before, the game was never pointed at the step, so the stage was never read and the check stayed forever. Seen live with a started Shield of Arrav after every other F2P quest was done.
- The partner check names what it waits for: "Confirm the partner for Shield of Arrav" (was "Shield of Arrav needs manual help or confirmation").
- Shield of Arrav is optional (it needs a partner from the other gang). When it is the only F2P quest left and it waits on a check, the Path shows the F2P skill checkpoints ("Next in F2P", marked "Shield of Arrav optional") with the "I have the partner" button above them. Before, the Path showed only the check. While its step is open in the route, the Path opens that step; once you skip it, the list appears.

Verified before delivery: 2,645 unit tests, the route gate (23 of 23 quests, no check, 1 of 211 turns with an unknown time) and 774 browser checks, including a new scenario for this case: every quest done but a started Shield of Arrav. It fails on 2.92.0 (the game is not pointed at the step and the Path shows only the check) and passes now. Also typecheck/build, data/fixtures, structure, unused-code and dead-CSS gates. The plugin code is unchanged since 2.87.0 (its 640 tests passed then). Paired timing against 2.92.0, two pairs: mean non-XP update script time −2% (12.1 → 11.8 ms) and −2% (11.9 → 11.6 ms); cold-start script time from −3% to +7%. Native Electron checks and the isolated Portable EXE run in the release workflow. The plugin's own stage reading is unchanged; that it resolves this check in the real game is not tested yet.
