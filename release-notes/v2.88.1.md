# OSRS Path 2.88.1

- Path: each quest in the planner's order now says in one short line what is unknown about it ("Time unknown: quest work") instead of "Not compared: its time is unknown (work), so it could be faster" on every row.
- Under the next action, Path shows that action's own reasons; how the planner weighed the other quests is folded under "How the planner chose". Before, the title was repeated and the planner's internal notes ("Keep the current objective unless a material improvement…") were always shown.

Verified before delivery: 2,637 unit tests and 769 browser checks; typecheck/build, data/fixtures, structure, unused-code and dead-CSS gates. The plugin code is unchanged since 2.87.0 (its 640 tests passed then). Paired timing against 2.88.0: mean non-XP update script time +7% (12.8 → 13.7 ms), within the 10% budget; the rise is on the Gear and Skills pages, which this change does not touch, while Path updates got faster, so it is likely run-to-run noise. Cold-start script time is lower on every measured page. Native Electron checks and the isolated Portable EXE run in the release workflow. No real-game testing is claimed.
