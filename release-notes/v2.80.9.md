# OSRS Path 2.80.9

Backup diagnostics now distinguish protected skipped records from a complete copy.

- Settings names a damaged or unsupported source or backup that could not be refreshed.
- Healthy character files continue copying. Protected original bytes remain untouched.
- A complete retry clears the affected scheduled-copy warning. Independent successful copies do not erase a first-write warning.
- A retained unsupported first-write copy is reported even when the primary save succeeds.

The existing Settings warning is reused; there are no extra panels or save-format changes. This does not add external file watching or claim interrupted-write recovery.
