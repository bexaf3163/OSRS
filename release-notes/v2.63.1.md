# OSRS Path 2.63.1

## Fixes from the final check

- Settings at a large interface scale (150%): the Preview now sits under the appearance settings when the two do not fit side by side. It was
  squeezed to a word or two per line.
- Gear without exchange prices: the page no longer says your weapon and amulet are "the best possible at your levels and money", and an exchange
  upgrade is no longer called "better than what you can afford". With no price, neither is known, and the page now says so.
- Inventory cleanup: "Keep 1 for Monkey Madness I. The item list has not loaded, …". The reason is now its own sentence instead of following a
  semicolon with a capital letter.
- Readiness: "Minotaur (level 12) suits your current kit best" (was "suit").

## What the final check covered

- All checks: 1205 unit tests, 573 plugin tests, 460 interface checks, including every main page at 100%, 125% and 150% interface scale (no
  sideways scrolling, no cut-off button text, no console errors).
- The release exe itself, run from a folder of its own: it opens, connects to a stub plugin, saves progress next to the exe, and closing the
  window ends the app and its launcher with nothing left in the temporary folder. Your own data and the copy you run were not touched.

## For developers

- `E2E_EXE=<path to the portable exe> npm run test:e2e` runs a release candidate (alone in its folder) with the same isolation as the source run.
  `UI_SCALES=1 npm run test:ui` adds the 100/125/150% pass.
- The test variable `OSRS_PUT_E2E_ROOT` now isolates packaged builds too. It only ever moves the data away from the player's.
