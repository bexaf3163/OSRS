# OSRS Path 2.102.0

- New Members quest: Dwarf Cannon (1 QP, 750 Crafting XP). It joins the early Members stage of a Members account's route and never shows in free-to-play mode. Its stages, tiles and texts come from Quest Helper and the Wiki through the quest pipeline. The toolkit step now leads to the broken multicannon at Captain Lawgof's camp, with the cannon highlighted.
- The plugin now follows Dwarf Cannon's stages in the game. Its quest progress is stored in game variable 0, and several of its objects (the dwarf remains, the crate with Lollk, the goblin cave entrance and exit) also have very low ids, starting at 0. The plugin used to reject id 0 as invalid, so the quest card would not have moved with the quest.

Verified before delivery: 2,629 unit tests (changed: id 0 is accepted, -1 is still rejected), the F2P route gate (23 of 23 quests, 0 of 211 turns with an unknown time), the Members route gate (37 of 37 quests, no check, 87 of 302 turns with an unknown time), the browser and Electron desktop checks, the plugin tests (new: Dwarf Cannon's stage table is accepted and reads varp 0), typecheck/build, data/fixtures, structure, unused-code and dead-CSS gates. Nothing was tested in the real game.
