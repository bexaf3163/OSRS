**Five improvements: bag-aware step details, a Home Teleport timer, a "fastest way" tip, bag cleanup advice, and time per stage.**

- **Step details that know your bag (in the game):** when the list is open, the step's details drop an errand you have already done ("; buy rope too" disappears if rope is in the bag) and a new row says what the bag has: "You have: Ball of wool x3, Rope", "in the bank: ...", "still needed: Onion x2", "not checked: ...". Each state is said apart, so something not checked is never called missing. A clause is dropped only if every item it names is in the bag.
- **Home Teleport timer:** the plugin now reports how long until the Home Teleport can be cast again. In "How to get there" the Home option shows "ready in 12 min" instead of promising a button that will not work. The value is checked against the clock before it is believed; if it does not look like a time, nothing is shown (never an invented timer). Not yet verified in the live game.
- **"Fastest way" tip:** a one-line hint under the step status when a fairy ring, charter ship, teleport or tablet clearly beats walking (at least 80 tiles). It says what it needs to be checked, or where to withdraw or buy a tablet first. It asks the plugin for your position once per step.
- **Bag cleanup:** in "What you need", a folded "Bag cleanup" lists things in the bag that this step and the nearest ones do not ask for, and how many slots they would free. It opens by itself when the bag is tight. Money, food, runes, staffs, teleports and jewellery are never listed, and with an unknown bag there is no advice.
- **Time per stage:** the Goals page has a "Time per stage" card: each step is timed from the previous one (so walking is included), a gap over 30 minutes counts as a break and is left out, and steps marked in bulk from the game are counted apart as "no time" instead of being guessed. Times start with the next step you mark done.

**Checked.** App tests, data checks, the production build, the browser interface checks and all plugin tests pass, including new tests for every item above. Not run in the live game: the cooldown value, the tip with a real position, and the new rows on the real screen.
