# OSRS Path 2.81.40

- RuneLite launched from OSRS Path now runs with a 2 GB G1GC heap (-Xms1024m -Xmx2048m -XX:+UseG1GC -XX:G1HeapRegionSize=8m -XX:MaxGCPauseMillis=10) so 117 HD, Quest Helper, Shortest Path and HUD surfaces avoid humongous-allocation GC pauses.
- The Ledger in-game guide reuses its backing image across hover, opacity and distance updates when dimensions match, and caches derived display and body fonts by size.
- Developer step and anomaly screenshots (	elemetryShots, 	elemetryEventShots) are now off by default so normal play avoids full-window OpenGL readbacks.
