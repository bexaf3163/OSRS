# OSRS Path 2.87.1

- Dragon Slayer is planned all the way through. Its later fights (Melzar's Maze, Elvarg) could not be "ready" before the quest starts, because the quest itself hands over the Maze key and the Anti-dragon shield, so the plan stopped at "Verify combat readiness". A fight ahead of the current step now counts as covered when the fight engine finds a safe way to win it; its training and kit are planned when you reach it, and until then the quest's remaining time is shown as unknown rather than guessed.
- Elvarg: the Anti-dragon shield is put on as the last step before the fight, after any training. Before, the plan put it on, then the training kit swapped it for a kiteshield, and back again.
- Melzar's Maze: nothing can hit you at the safespot, so armour that lowers your magic bonus is taken off before you cast, as the route already says. The estimate now counts the rest of your kit (in 2.87.0 a full metal set made Water Strike look impossible).
- A fresh account now completes all 23 F2P quests through planned actions in the turn-by-turn simulation (earn, buy, equip, train, quest), with no check left. The simulation is now a repeatable gate for developers, `npm run gate:f2p`, with a fixed price snapshot: it fails when the plan stops at a check.

Still open: remaining-time estimates are mostly unknown until each preparation is measured.

Verified before delivery: 2,634 unit tests, the route gate (23 of 23 quests, no check) and 769 browser checks; typecheck/build, data/fixtures, structure, unused-code and dead-CSS gates. The plugin code is unchanged since 2.87.0 (its 640 tests passed then). Paired timing against 2.87.0: mean non-XP update script time +1% (13.2 → 13.4 ms), cold-start script time at most +2%, within the 10% budget. Native Electron checks and the isolated Portable EXE run in the release workflow. No real-game testing is claimed.
