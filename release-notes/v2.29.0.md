**Your progress can no longer be lost by deleting the program, and "Sync with the account" restores it from the game.**

**Safer storage**

- Every hour (and at launch) the progress is copied **outside the program folder**, into `%APPDATA%\OSRS Path\progress-copies`. This is on by default. Deleting the exe and the `OSRS-Put-data` folder no longer takes the copies with it.
- A fresh install (no data folder yet) **restores itself** from the newest valid copy at launch: all profiles and the profile list. Files that already exist are never overwritten.
- Besides the dated copies (last 14 per profile) there is now a `latest` copy that follows the progress during the day, so a deletion loses minutes, not a day.
- The profile list now also lives in a file next to the progress, so profiles survive a lost window storage.
- Settings → "Progress copies": see both folders, add a folder of your own (for example in OneDrive, which also protects against a wiped disk), make a copy now, or turn the automatic copy off.

**Restoring from the game**

- "Sync with the account" now also marks the steps that the game-confirmed steps require (they were done on the way), including the ones with no in-game signal, in route order. Everything is shown in a list before you confirm, and it can be undone.
- Notes and manual skips cannot be read back from the game.

**Checked.** App tests, the data checks and the build pass. The copy and restore code is covered by tests on real files. Not run in the live game or on a fresh Windows install: after updating, open Settings → "Progress copies" and press "Make a copy now" to see the folder.
