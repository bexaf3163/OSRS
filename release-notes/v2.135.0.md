# OSRS Path 2.135.0

Training is always Balanced now. The XP / Balanced / Money switch on the skill cards is gone, together with the XP-first and money-first rules behind it. Balanced picks each training method by the practical time to the goal, counting the setup of missing items, attention and material cost, and buys a better tool only when the time it saves is worth more than its price. A choice saved by an older version is cleared at start.

The quest route, the preparation, the Money page and the free-to-play checkpoints are unchanged.

Verified before delivery: 2,649 unit tests, the route gate (all 23 free-to-play quests and all 77 Members-route quests finish), the browser checks on every page, the Electron desktop checks, the plugin tests, typecheck/build, data/fixtures, structure, unused-code and dead-CSS gates. Nothing was tested in the real game.
