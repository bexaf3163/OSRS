# OSRS Path 2.136.0

Route planning is faster. The training forecast behind every quest estimate now reuses work for equal player states instead of redoing it per quest and per level, so a Members turn plans about 4 times faster with the same results.

The route gate checks F2P and Members on separate runners, so a release waits for the longer Members replay only.

Verified before delivery: 2,649 unit tests, the route gate (all 23 free-to-play quests and all 77 Members-route quests finish, together in 20 minutes instead of 71), the browser checks on every page, the Electron desktop checks, the plugin tests, typecheck/build, data, structure, unused-code and dead-CSS gates. Nothing was tested in the real game.
