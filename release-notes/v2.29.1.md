**Fixes found while testing 2.29.0 on a real PC with the game: the progress copies can no longer be overwritten by an older state, and "Sync with the account" understands level goals.**

- **Safer copies.** The "latest" copy now follows every save (seconds, not an hour), and a state that is **older** than the copy never replaces it. Found when a freshly started copy of the program, which began from an old state, overwrote the newest copy.
- **A fresh install restores the newest state.** A new data folder that starts with an older progress file (taken over from an earlier installed version) is now refreshed from the newer copy.
- **"Sync with the account" closes level-goal steps.** A step such as "Mining to 15" or "Fishing to 20 and Cooking to 15" is offered as soon as the levels are reached; the food or ore listed with it is no longer required, because it is eaten or sold on the way. Quest steps that need items are still left alone.

**Checked.** App tests, the data checks and the build pass. On a real PC with the game: the program found 14 steps the game confirms and marked them (readiness in the game went from 80% to 92%), the in-game list, the Tip tab and the side panel worked, the plugin journal showed no errors, and a fresh copy of the exe filled its data folder from the copies.
