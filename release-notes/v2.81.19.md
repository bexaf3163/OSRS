# OSRS Path 2.81.19

- Faster: about 70% less work on each game update and roughly half the start-up blocking time, measured on Windows. Recommendations, saves and the Ledger design are unchanged.
- Smaller: the unused Inter font, 397 never-matching style rules, three unused components and their dead code are removed; the in-game guide font Sora now ships inside the RuneLite plugin.
- Accessibility: the title bar, the current-action heading and the Journal quest preview have correct landmarks and heading levels for screen readers.
- The app records its first-paint time in `startup.log` in its data folder.
- Project upkeep: structure, unused-code and dead-CSS checks run in CI, a one-command version bump, and faster unit and browser test runs.
