# OSRS Path 2.50.0 — Cockpit and Companion strip

A redesign of how the Path page gives information. The data, the preparation engine, the in-game guide and the bridge are unchanged; this is the presentation.

## Cockpit (the big window)

- **One screen, no tabs.** What to do now, the walkthrough, what the stage needs, where it is and what it pays sit side by side. On a wide window it is three columns; on a medium one two; on a narrow one a single column.
- **One main button.** "Show in game" leads the game to the current line (the line's own point while the game confirms it, otherwise the step's point).
- **Preparation, Travel and Details slide in** from the side on **P**, **T** and **D** (or the buttons) and never push the page down. **Esc** closes them.
- **The verdict follows the stage.** While the game confirms the line you are on, what the quest used up earlier ("Used earlier in this quest") is folded away instead of being shown as Missing, and the ready ring and the verdict count only what the stage still needs.
- No empty boxes and no repeated verdict: "Start the step" is gone (Show in game does it), each fact is said once.

## Companion strip (compact view)

- A narrow panel for the side of the game with four views of the same step: **Now** (current line, next lines, what the stage needs, Done and Skip), **Bag** (the verdict and the list), **Route** (the stage, jump to any step), **More** (the walkthrough, Travel, Details).
- **Full workspace** goes back to the cockpit. The state is shared; nothing is a second copy.
