# OSRS Path 2.49.0 — Path uses the window; no empty guide in the game

## Path page

- **The walkthrough is open from the start.** Steps, Preparation, Travel and Details are tabs; Steps is selected, so the quest overview shows without a click.
- **"What you need" stands beside the action on a wide window.** One list (each thing once, with its state) and the reward, to the right of "What to do now". On a narrower window, or at large text, the same list sits inside Steps as before.
- **The page uses the width.** The step column is up to 1440 px wide instead of 960 px.
- **The current quest line is in view.** The overview list ends at the bottom of the window and scrolls to the current line, so line 17 of 18 no longer needs a page scroll.
- **Preparation repeats less.** The chip copy of the list is gone; "not everything is checked" and "target saved" are each said once. A named problem (levels, items, coins, a quest) keeps its own heading.
- **No empty boxes.** A step without a walkthrough or without anything to bring no longer draws an empty panel. A step with no stage data shows its walkthrough open instead of folded away.

## Game guide

- **Shield of Arrav has a walkthrough in the game.** The app has no stage data for this quest (it never had), so the game showed only "Reldo, ~7 tiles" from the first line to the last. Its walkthrough is now a list in the guide: the current line, "done" to move on, "back" to reread. The line you reached is kept across a client restart.
- The Shield of Arrav walkthrough is 18 short lines instead of 5 paragraphs. Two of the paragraphs were too long to be sent to the game and were silently dropped (the whole Phoenix Gang and Black Arm Gang parts).

**Limits of the Shield of Arrav walkthrough:** the game cannot confirm its lines, so only "done" moves it; the lines have no map points, so the arrow stays on Reldo; both gangs are in one list (the lines say which gang they are for).

## Was anything lost in the redesign

Checked 2.48.3–2.48.9 against 2.48.2: no screen or component was removed, the plugin's rules for when the guide and the target plate are drawn are unchanged, and the data files are unchanged apart from the added icons. Shield of Arrav showing almost nothing in the game is not a regression: it is the one F2P quest without stage data.

**Checked:** build, TypeScript tests, data consistency, the full Java suite (new `ManualWalkthroughTest` with the real lines the app sends), the production UI run with new checks (walkthrough open without a click, the list beside the action once, Preparation without the repeated verdict). The real Electron shell check runs in the release workflow. **Not yet checked in the live game.**

Restart RuneLite through OSRS Path after updating.
