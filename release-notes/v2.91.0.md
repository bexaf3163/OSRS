# OSRS Path 2.91.0

- The remaining time is known almost all the way through. In the fresh-account route it was unknown on 51 turns (most of Dragon Slayer's Elvarg preparation); now it is unknown on 1 of 211. The quest-length band (OSRS Wiki length category) already includes the quest's fight. The planner took out the fight as your current, unprepared kit would do it, which during training was longer than the whole band, so the time went unknown. It now takes out the fight the plan is preparing for. Training and kit are still counted separately as preparation.
- Free items from a quest NPC (the Anti-dragon shield from Duke Horacio once Dragon Slayer has started) get a walking time, like any other free pickup. Before, they always made the preparation time unknown.
- Bow fights count their arrows. Each shot uses an arrow from the quiver, so the fight's kit now lists the arrows it needs (for example 27 Mithril arrows for a Black Knight with a maple shortbow at Ranged 50). With too few worn, the plan gets the rest first instead of calling the fight ready. The fight line says "up to N arrows".
- Arrows in the bag join the ones you wear: with part of the stack worn and the rest in the bag, the plan says "Equip" instead of buying more.

Still open: one turn has an unknown time (fetching Elvarg's shield; the fight's training is priced once the shield is in hand). The kit compared for a fight is still melee kit, so a better bow or arrows are not yet proposed.

Verified before delivery: 2,644 unit tests, the route gate (23 of 23 quests, no check, 1 of 211 turns with an unknown time, down from 51 of 209) and 769 browser checks; typecheck/build, data/fixtures, structure, unused-code and dead-CSS gates. The plugin code is unchanged since 2.87.0 (its 640 tests passed then). Paired timing against 2.90.1, two pairs: mean non-XP update script time +9% (12.7 → 13.8 ms), then 0% (13.6 → 13.7 ms), both within the 10% budget; single rows moved up to ±50% in both directions between pairs. Cold-start script time ranged from −0% to +11% (the Shopping page in the first pair, +1% in the second). The route gate's planner time per turn fell from 0.66 s to 0.60 s. Native Electron checks and the isolated Portable EXE run in the release workflow. No real-game testing is claimed.
