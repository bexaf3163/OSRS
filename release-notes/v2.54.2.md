# OSRS Path 2.54.2 — two things the first live check of 2.54.1 found

Found by playing the 2.54.1 build on World 316 and reading what the app and the plugin said for the real account.

- **Stock-up suggestion that could not work.** The road's supply stop could suggest buying one Fire rune for a Varrock Teleport while the Law rune was also missing and the Exchange was too far to be worth it. A way is now stocked for only when everything it still lacks can be had on the same trip; if the Exchange and a rune shop are both close, the trip lists both, nearest first. What is not known to be short (an unread bank) does not hold a way back.
- **Fishing 1-40 (S6-02): the arrow and the tools now follow the climb.** The map arrow still led to Musa Point (Fishing 40+) while the card told you to net shrimps first. The step now has three spots in level order — Draynor nets (1-20), Barbarian Village fly fishing (20-40), Musa Point (40-50) — and the arrow starts at the first. The requirement is the first tool, a small fishing net, and any later tool counts instead; the fly fishing rod, feathers, lobster pot and harpoon are recommended. Before this, a level-1 account was sent to the Exchange to buy a harpoon first.
- **Checked:** `tsc`, build, 1014 Vitest tests, `check-data`, the full Java suite, UI smoke. Checked in game: the stock-up suggestion is gone for the real state, the arrow for S6-02 reads "Draynor Bank: take Small fishing net", the trade-restriction note shows the unread hours as unknown, and the step tasks match the worn items.

Restart RuneLite through OSRS Path after updating.
