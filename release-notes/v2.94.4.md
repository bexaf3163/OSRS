# OSRS Path 2.94.4

- The two Reference pages a new player opens from the welcome card are rewritten for beginners.
- "Signing in and setup" now covers the whole first run in five steps: the Jagex account and launcher, the game in RuneLite, Tutorial Island, linking OSRS Path (Settings → RuneLite → "Launch RuneLite with the bridge", and what to do when the Jagex sign-in is not saved), and playing without RuneLite. Below it: keeping the account safe (authenticator, bank PIN, where to type the password) and graphics tips for any laptop with built-in graphics instead of one laptop model. The idle logout can be raised to 25 minutes (Settings → Gameplay), not 30 as it said before.
- "If you do not know what to do" now walks through the app itself instead of general rules: Journey's heading and "Show in game", Fix for preparation, Skills for a missing level, Money for coins, how much food to bring (the route buys it), the quest walkthrough and Wiki tab, and "Next in F2P" when every free quest is done.
- The Reference intro no longer points at a "Step-by-step plan" section that does not exist.

Verified before delivery: 2,618 unit tests (the Reference still says the route buys its food), the data consistency, structure and Reference and page browser checks, re-run on the new text; the full 797 browser checks, the route gate and the Electron desktop checks ran on the same app code for 2.94.3. Text only: no timing comparison. The idle-logout limit was checked against the OSRS Wiki. The plugin code is unchanged since 2.87.0. Nothing was tested in the real game.
