# OSRS Path 2.92.0

- Fight preparation for a bow user now compares a better bow and arrows. When the fight is not safe with your current bow, the planner also weighs the bow your Ranged level unlocks and the strongest arrows each bow fires, and picks the fastest safe option. Each option is costed and timed with its trip, like any other kit. For example, at Ranged 20 with a Shortbow and Bronze arrows against a Black Knight, the plan now says "Get Willow shortbow" (about 40 gp). Before, it could only offer Ranged or Defence training, or stop at a check when your XP was not read.
- A bow only fires the arrows its tier takes (adamant arrows need a maple shortbow in F2P). A fight with arrows the bow cannot fire is no longer estimated as if it could; it stays unknown.

Still open: armour for a bow fight is still chosen by melee defence. Ranged armour (leather, studded, green d'hide) is not yet compared. Training plus a new bow together is not compared either; each is weighed on its own.

Verified before delivery: 2,645 unit tests, the route gate (23 of 23 quests, no check, 1 of 211 turns with an unknown time; the route is a melee one, so the bow alternatives are covered by unit tests) and 769 browser checks; typecheck/build, data/fixtures, structure, unused-code and dead-CSS gates. The plugin code is unchanged since 2.87.0 (its 640 tests passed then). Paired timing against 2.91.0, two pairs: mean non-XP update script time +1% (13.3 → 13.4 ms), then −3% (12.8 → 12.4 ms). Cold-start script time ranged from −6% to +11% (Shopping in the first pair; −4% in the second). Native Electron checks and the isolated Portable EXE run in the release workflow. No real-game testing is claimed.
