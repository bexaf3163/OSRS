# OSRS Path 2.72.0

**Integration fixes from the consolidated review.**

- **The readiness ring tells the same story as its verdict.** Next to "Preparation required (1 item)" it counts the step's own items (it used to count the whole next trip, so "1 item" sat beside "ready 9%"). Next to "Not everything is checked" there is no percentage any more: unknown is not a share.
- **"Why this plan?" opens the comparison itself.** In the compact layout the link opened the Preparation view but left the fold closed.
- **Shop names without a town.** Shopping no longer shows "Buy at Silk trader —" with nothing after the dash. Traders that only buy an item (listed with a placeholder price of 10,000,000,000 gp) are no longer offered as shops.
- **Shopping links to the Money section** next to "Raise the coins" when the trip is short of coins.
- The window-scaling review (100, 125 and 150%) now includes the Money page.
- A font comparison sheet for the in-game panel, drawn the way the plugin draws text (Java2D, the card's sizes): Sora as shipped, Sora with exact letter spacing, Sora without the renderer-made bold, the same for Inter, and Segoe UI and Dialog for reference. It is for the owner's choice; the shipped font is unchanged.
