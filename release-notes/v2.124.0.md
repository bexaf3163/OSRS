# OSRS Path 2.124.0

- Members routes now include Client of Kourend, after X Marks the Spot. The guide covers the trip to Veos at Port Piscarilius, the five Kourend general stores, the Dark Altar orb and the return to Veos. It also covers the feather to bring, which you can buy at Gerrant's Fishy Business in Port Sarim. The quest gives 1 quest point, so the Members total is now 109.
- The quest-drafting tool works again for newer Quest Helper data, which names quest progress ids instead of numbering them. Quest cards that list a single prerequisite under "Completion of the following quest" now read that prerequisite.

Verified before delivery: 2,647 unit tests, the route gate (all 23 free-to-play quests and all 53 Members quests finish), the browser and Electron desktop checks, the plugin tests, typecheck/build, data/fixtures, structure, unused-code and dead-CSS gates. Nothing was tested in the real game.
