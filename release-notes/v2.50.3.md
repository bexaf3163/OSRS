# OSRS Path 2.50.3 — a calmer, clearer first hour

A pass over every screen of the app and the in-game guide, aimed at someone opening it for the first time.

## First screen

- **A short welcome** for a new player: what to read, what to press, and that RuneLite is optional. It disappears with the first step you finish or on "Got it".
- **One obvious next action.** "Done — next: <step name>" sits right under the current instruction (it replaces the quiet "Mark as manually completed" at the end of the page). The footer buttons say "Previous step" / "Next step" instead of step codes.
- **Less noise.** The "Ready to set off" box is gone when a step has nothing to check; the "Where" card is gone for steps with no place on the map; the "Up next" line that repeated the Done button is gone; the same sentence is no longer shown twice (the place line and a grey box).
- **No alarm without RuneLite.** The amber "RuneLite is offline" warning is a quiet note with a "Set up RuneLite" link. Without RuneLite the list says "Bring" instead of "Not checked" on every line.
- **Long instructions fit.** A long action title is set smaller so it does not take four lines.
- The P / T / D key chips are gone from the buttons (the shortcuts still work); the cryptic header icon for density is gone (it is in Settings → Appearance).

## Other pages

- **Journal:** one set of tabs instead of two.
- **Skills:** a card no longer repeats its own name as a subtitle.
- **Settings:** play style, preparation and the helpers are folded under "Advanced"; the RuneLite page starts with the Launch button and a shorter explanation.
- **Route drawer:** the close button no longer covers "To the current step".
- **Search bar** shows its label at every width. Light theme: muted text and gold labels are darker (they were just under the readable contrast).
- **Compact strip:** a short welcome; the Done button and "Previous / Next" use names.

## In the game

- The guide's tab strip no longer shows "Advice · 0" when there is no advice.

Presentation only; the data, the preparation engine and the bridge are unchanged.

**Checked:** build, TypeScript tests, data consistency, the full Java suite, the production UI run (334 checks), screenshots of the real build at 390, 768, 1100, 1440 and 1900 px, dark and light. Not checked in the live game.

Restart RuneLite through OSRS Path after updating.
