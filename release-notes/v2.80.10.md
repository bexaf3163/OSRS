# OSRS Path 2.80.10

Backup warning history now honours its actual disk-write result.

- If warning history cannot be saved, Settings says so while the successful primary save remains acknowledged.
- Unchanged diagnostics retry saving once the path becomes writable; an earlier failure no longer suppresses the retry.
- First-write warning preservation is checked through a fresh native process in source acceptance, separately from packaged acceptance.

No new panels or save format. This addresses diagnostic persistence, not power-loss durability or external-file watching.
