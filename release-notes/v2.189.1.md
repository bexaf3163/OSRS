# OSRS Path 2.189.1

2.189.0 was never published: a cache limit it added made Members planning about five times slower, and the speed check stopped the release. That limit is gone, and every fix of 2.189.0 ships here, with these:

## Grand Exchange offers count again

RuneLite 1.13.8 changed how an offer reports the coins it holds, so the plugin dropped every offer and the app never saw items or coins waiting in the exchange. The plugin is now built against RuneLite 1.13.8. Every release now checks each RuneLite call of the plugin against the newest RuneLite before it is published.

## More fixes

- A trip to buy an item no longer ends because the bag already holds one: the arrow ends once the bag holds more than when it started.
- Climbing into a cave whose inside lies far away on the map, such as the Stronghold of Security or Zanaris, no longer counts as a teleport.
- Quest steps that look for objects or items on the ground read the scene once per game tick instead of once per event.
- Members monsters with several levels show their level in the fight estimate again.
- When the app cannot install an update from its folder, it says why instead of doing nothing.
- The weekly Wiki watch lists only real quests and miniquests, keeps titles that end in a dot, writes links that always work and closes its issue when nothing is left to review.

The rest of the 2.189.0 fixes are in its notes: banknotes in the guide, bag space for Rune essence, Members ranged armour, magic defence, step names instead of codes, and more.

Verified before delivery: all app and plugin tests, the F2P and Members route gates, the UI tests and the RuneLite check. Nothing was tested in the real game.
