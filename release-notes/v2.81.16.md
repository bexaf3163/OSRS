# OSRS Path 2.81.16

- Connected furnace smelting to the existing Skills planner. Usable owned ores/coal, level, budget and current prices determine the recipe and furnace guide.
- Iron, steel, mithril and adamant anvil families now include one-bar daggers and three-bar warhammers alongside platebodies, with actual unlocks and reusable hammer requirements.
- Corrected legacy Smithing level and cost claims. Firemaking's five supported log tiers and shared processing preparation/checkout have additional regression coverage.
- Ordinary iron smelting retains50% success; ring of forging, Blast Furnace and unmodelled bonuses are not assumed.
- Ledger design/fonts are unchanged. Real-game acceptance remains Claude's; the canonical plan is PROJECT_HANDOFF.md.
