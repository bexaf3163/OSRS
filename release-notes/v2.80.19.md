# OSRS Path 2.80.19

Members oak and teak methods now use the existing gathering model instead of remaining guide-only. Teak estimates use normal chopping, the player's usable axe, tree lifetime, respawn and verified Isle of Souls spawns. The old 34,000–93,000 XP/h range mixed ordinary play with tick manipulation and has been removed.

- All six current Woodcutting catalogue methods now have model dispatch. This is not complete support for every tree, axe mechanic or Members training method.
- Unsupported owned tool mechanics remain unestimated rather than being counted as a Bronze axe. Explicitly planned tools must meet level/membership requirements; they are not silently replaced with a different tier. Shared Skills and funding gathering calculations inherit these guards.
- Members methods cannot be rated on a free account merely because a resource also has free locations. Approximate location declarations preserve their membership flag.
- The added locations use cut-and-drop estimates. Seers' Village is an approximate oak location; banking there and from the supported teak spot is not modelled. No bank income is invented.
- The compact interface, saves, route targets, adopted plans, bridge protocol and launcher arguments are preserved. Live-game acceptance belongs to Claude.

Data was regenerated with `npm run build-skilling` against the OSRS Wiki: [Teak tree](https://oldschool.runescape.wiki/w/Teak_tree), [Woodcutting](https://oldschool.runescape.wiki/w/Woodcutting), [Axe](https://oldschool.runescape.wiki/w/Axe) and [Game tick/Action lengths](https://oldschool.runescape.wiki/w/Game_tick/Action_lengths). Automated coverage includes newly declared content, unknown and unsupported tools, membership boundaries, shared funding timing and desktop method-to-arrow consistency.
