# OSRS Path 2.48.9 — fixes after the redesign review

Found by reviewing 2.48.3–2.48.8 in the code, in the built app and in the live game.

- **The desktop action follows the quest again.** "What to do now" took the quest cursor only from `/status`, which the app asked for at login and reconnect, so it stayed on the line you were on when you logged in and fell back to "Starting point" on the next quest. The plugin now announces a moved cursor (a STATUS event on change, nothing new in the protocol) and the app asks again.
- **Section strips show all their links.** On Skills, Gear, Shopping, Journal and Reference the first link took the whole width above 700 px and the others (the other skills, the Reference sections) were out of view.
- **Sidebar order.** Between 1000 and 1199 px, and at text above 120%, the section list stood under Quest points and Settings (at 150% part of it was below the window).
- **Game guide: a warning is drawn once.** With the list open, the recovery warning after a death ("You died: step ... is far away") and a stage warning appeared twice, at the top and at the bottom.
- **Game guide: no repeated "Details:" row.** The open list repeated the current action word for word.
- **"or" is set apart only as a whole alternative.** "Defeat the Ancient Guardian / or mine 4 pillars" stays; "melee or ranged only" and "essence (rune or pure)" are no longer cut in two with the second half muted (game guide and desktop).
- **Quest overview** scrolls its own list to the current line on a long quest (it used to show lines 1–7 while you were on line 16).

**Checked:** build, 897 TypeScript tests, data consistency (0 errors, 0 warnings), the full Java suite (new cases in `BridgeServerTest` and `ModernGuideTest`), the production UI run with new checks for the strips, the sidebar order and the moving cursor. The live game check was done on 2.48.8 (expand, Advice, collapse; the character was not moved); the fixes themselves are covered by tests and are **not yet re-checked in the live game**. The real Electron shell check runs in the release workflow.

**Known, not changed:** the open guide can cover the chat buttons when the list is long (it moves up to fit); the header is tall at 150% text; the guide shows two different distances while you are in Death's Office (an instance).

Restart RuneLite through OSRS Path after updating.
