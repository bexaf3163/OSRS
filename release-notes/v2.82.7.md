# OSRS Path 2.82.7

- Path says when the plan will update: under the planner's order, "The plan updates when Quest X completed in game, or when your levels, items, coins, quests or goal change." It names the evidence that ends the current action.
- Live travel advice uses real walking routes. The "which teleport or walk" choice (Path's travel ribbon and the in-game arrow/HUD advice) compares the shortest known paths around rivers, walls and buildings, from the shared route worker, instead of straight lines. A leg with no known route still uses the straight line, and the walk option says so. Before, a teleport could lose or win against a walk that is not possible in a straight line.
- The route worker keeps one waiting request per caller, so a travel request never cancels the planner's own route request.
- When the planner's next action has no route step (for example "Read Below Ice Mountain in the quest journal"), the in-game HUD shows that action instead of nothing. A detour or funding plan still takes the card first.
- Live in-game acceptance of this release is still pending.
