# OSRS Path 2.90.1

- Fight preparation for a bow user: when the fight is not yet safe with your bow, the planner now compares training Ranged and Defence (and Ranged training at NPCs counts its Hitpoints XP, as melee training does). Before, it could only propose Attack or Strength levels, which never help a bow. Melee users are unchanged.

Still open: the kit compared for a fight is melee kit; a better bow or arrows are not yet proposed as fight preparation.

Verified before delivery: 2,642 unit tests, the route gate (23 of 23 quests, no check, 51 turns with an unknown time) and 769 browser checks; typecheck/build, data/fixtures, structure, unused-code and dead-CSS gates. The plugin code is unchanged since 2.87.0 (its 640 tests passed then). Paired timing against 2.90.0: mean non-XP update script time +1% (13.5 → 13.6 ms), cold-start script time lower on every measured page. Native Electron checks and the isolated Portable EXE run in the release workflow. No real-game testing is claimed.
