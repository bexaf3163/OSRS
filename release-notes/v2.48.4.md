# OSRS Path 2.48.4 — live desktop audit refinements

The Clear Path design is retained. RuneLite launch and hint controls now use proper action rows, appearance density controls align with the form, profile inputs follow the theme, and sticky panels account for larger text. Current step codes stay on one line.

A connected RuneLite client at the login screen no longer claims that a saved target or arrow is live in the game. The current action, step status, quest overview, Travel hints and navigation badges wait for the character to enter the world. Saved targets, resend/clear controls and existing preparation calculations are preserved.

`CLAUDE_REDESIGN_HANDOFF.md`, referenced by `CLAUDE.md`, records the redesign, changed components, retained functionality, audit findings and required checks for future work. No new progression or preparation engine is introduced.

Update through Settings → App, or put the portable executable beside the existing `OSRS-Put-data` directory. The in-world visual audit remains pending manual login; automated render tests are not presented as a live bank, exchange or combat check.
