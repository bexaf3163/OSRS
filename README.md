# OSRS Путь

Личный трекер прогресса в Old School RuneScape. Маршрут V2: 51 шаг бесплатной версии (этапы 1–6)
и 12 шагов подписки (этапы 7–9), 12 навыков с планом прокачки и 8 навыков подписки, цели по этапам,
квесты, справка и плагины RuneLite. Встроенный инспектор OSRS Wiki: цена на бирже, магазины,
бесплатные места появления и дроп для 191 предмета.

Без сервера и аккаунтов. Есть программа для Windows (exe), а в браузере работает офлайн
и ставится на экран «Домой» iPhone.

## Программа для ПК

Готовые файлы — на странице [Releases](https://github.com/bexaf3163/OSRS/releases/latest):

- **`OSRS-Put-Setup-<версия>.exe`** — установщик: ярлык на рабочем столе и в «Пуске», удаляется
  через «Установленные приложения». Данные — в `%APPDATA%\OSRS Путь`.
- **`OSRS-Put-<версия>-portable.exe`** — без установки. Данные лежат **рядом с exe**, в папке
  `OSRS-Put-data`: программу можно носить на флешке вместе с прогрессом. При первом запуске
  переносная версия забирает прогресс установленной, если он есть.

Прогресс хранится дважды: внутри программы и файлом `progress.json` в папке данных —
файл спасает, если внутреннее хранилище пропадёт. Где лежит папка, видно в «Настройках».
Браузер и телефон хранят свой прогресс отдельно; переносить — через экспорт и импорт (ниже).

Exe не подписан сертификатом, поэтому при первом запуске Windows SmartScreen может показать
«Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае».

**Внешний вид** (шестерёнка → «Внешний вид»):

- **Масштаб интерфейса** — 80–200 %. Клавиши: Ctrl + «+» / «−», Ctrl + 0 — сброс, Ctrl + колесо мыши.
- **Подстраивать под размер окна** — растягиваешь окно шире 1280 точек, и всё становится крупнее
  (до 1,5×), сужаешь — мельче (до 0,9×). Узкое окно получает раскладку как на телефоне.
- **Размер шрифта** — отдельно от масштаба: только текст.
- **Поверх всех окон** — удобно держать рядом с игрой.

Всё запоминается между запусками. Ссылки на вики открываются в обычном браузере. Меню скрыто —
показывается по Alt; обновить — Ctrl+R.

## Режимы F2P и Members

Переключатель `🛡️ F2P | 👑 Members` в шапке. В режиме Members появляются этапы 7–9,
навыки подписки на вкладке «Навыки», квесты подписки и подсказки для подписчиков в шагах F2P.
Отметки не теряются при переключении.

## Переход с первой версии маршрута

В V2 шаги перенумерованы. Сохранённый прогресс V1 (в программе, в браузере или файлом импорта)
переносится сам: отметки и заметки переезжают на соответствующие шаги V2 по таблице
`V2_FROM_V1` в `src/lib/progress.ts`, а полная копия старого прогресса остаётся внутри (`legacy`).

У трёх шагов (S1-03, S1-04, S2-01) в V2 появились важные требования. Если они уже отмечены,
на «Пути» появится баннер «Обновление гайда до V2!»: можно посмотреть изменения, вернуть шаги
в активные (очки квестов при этом не отнимаются) или скрыть предупреждение.

## Запуск

Нужен Node 22.18 или новее (скрипты данных написаны на TypeScript и запускаются самим Node).

```bash
npm install
npm run dev
```

Откроется `http://localhost:5173`.

| Команда | Что делает |
|---|---|
| `npm run dev` | Локальная разработка |
| `npm run build` | Проверка типов и сборка в `dist/` |
| `npm run preview` | Открыть собранную версию (`http://localhost:4173`) |
| `npm test` | Юнит-тесты (Vitest) |
| `npm run check-data` | Проверка маршрута, базы предметов и текста; сверка навыков и справки с гайдом |
| `npm run parse-guide` | Перенос навыков, целей, справки из `osrs-guide.md` → `src/data/*.json` |
| `npm run build-items` | Собрать базу предметов с OSRS Wiki (нужен интернет) |
| `npm run check-links` | Проверить все ссылки и картинки вики в данных (нужен интернет) |
| `npm run icons` | Перерисовать иконки в `public/` |
| `npm run desktop` | Собрать и открыть программу для ПК (Electron) |
| `npm run dist:win` | Собрать exe: установщик и переносную версию в `release/` |

## Выпуск новой версии

1. Поднять `version` в `package.json` (её видно внизу «Настроек»).
2. `npm run check-data`, `npm test`, `npm run check-links`, `npm run dist:win`.
3. Закоммитить, запушить и выложить exe:

```bash
gh release create v2.1.0 release/OSRS-Put-Setup-2.1.0.exe release/OSRS-Put-2.1.0-portable.exe --title "OSRS Путь 2.1.0" --notes "Что изменилось"
```

При каждом пуше GitHub Actions прогоняет `check-data`, тесты и сборку (`.github/workflows/checks.yml`).
Сетевые `build-items` и `check-links` в CI не запускаются.

## Как выложить веб-версию

`npm run build` собирает статическую папку `dist/`. Все пути в ней относительные, поэтому
она работает из любого адреса: корня домена или подпапки.

**Netlify.** Перетащи папку `dist` на [app.netlify.com/drop](https://app.netlify.com/drop).

**GitHub Pages.** На приватном репозитории Pages работает только на платном тарифе GitHub.
Для публичного репозитория опубликуй `dist`, например так:

```bash
npm run build
npx gh-pages -d dist
```

и в настройках репозитория (Settings → Pages) выбери ветку `gh-pages`.

**На iPhone:** открой адрес в Safari → «Поделиться» → «На экран „Домой“». После первого
открытия приложение работает без интернета (цены биржи и живой поиск по вики — только онлайн).
Новая версия подхватывается при следующем запуске после того, как телефон увидел её онлайн.

## Перенос прогресса между устройствами

Синхронизации нет, перенос — файлом:

1. На старом устройстве: шестерёнка → **Экспорт прогресса** (на iPhone ещё есть **Поделиться файлом** —
   удобно отправить через AirDrop или сохранить в «Файлы»).
2. На новом устройстве: шестерёнка → **Импорт прогресса** → выбрать файл → **Заменить**.

Импорт заменяет прогресс целиком; сразу после замены его можно отменить в появившемся сообщении.
Файлы первой версии тоже принимаются — они переносятся на V2 так же, как сохранённый прогресс.

Важно для iPhone: приложение с экрана «Домой» хранит данные **отдельно** от вкладки Safari.

## Данные

- **Маршрут V2** — `src/data/steps.json` и `stages.json`, источник правды для шагов. Правятся руками,
  после правки — `npm run check-data`.
- **Навыки, цели по уровням, опыт, плагины, справка** — из `osrs-guide.md` через `npm run parse-guide`
  (если есть ошибки, файлы не перезаписываются). `check-data` ловит ситуацию, когда гайд поменяли,
  а `parse-guide` не запустили.
- **База предметов** — `src/data/f2p-items.json`, собирается `npm run build-items` с OSRS Wiki
  (Bucket API: описание, цены у торговцев, дроп; места появления — из статей). Скрипт вежливо
  ждёт между запросами и кэширует ответы в `node_modules/.cache`; `--fresh` — собрать заново.
  Он же проставляет ID и иконки предметам в шагах.
- **Цены биржи** — живые, с prices.runescape.wiki; держатся в памяти 5 минут.

Что проверяет `check-data`: номера и этапы шагов, зависимости, очки квестов (F2P — 46,
с подпиской — 66) и совпадение с «Наградой», достижимость порогов по очкам, этажи в формате
`Ground floor (1-й этаж / земля)`, у предметов шагов — запись в базе с той же иконкой и русское
название, 120+ предметов в базе, текст — заглавная буква в начале, известные опечатки, парные скобки
и кавычки.

## Как считается

- **«Что делать сейчас»** — первый по порядку незакрытый шаг, у которого закрыты все зависимости
  и хватает очков квестов.
- **«Отметить выполненным»** в карточке сворачивает её и раскрывает следующий незакрытый шаг;
  страница прокручивается, только если он не виден.
- **Закрытый шаг** — сделанный или пропущенный. Пропустить можно только необязательный S3-05
  (Shield of Arrav); очков он тогда не даёт, и максимум F2P становится 45 из 46.
- **Очки квестов в «Целях»** считаются из маршрута V2 по этапам.
- **Строка плана прокачки** — по введённому уровню: диапазон «15–30» включает 15, но не 30.
  Ближний бой — по отстающему из атаки, силы и защиты.
- **Этажи** — по-британски, как в игре: Ground floor — 1-й этаж (земля), 1st floor — 2-й, 2nd floor — 3-й.
- **Опыт** — стандартная формула OSRS.

## Устройство

```
osrs-guide.md          источник навыков, целей и справки
scripts/               parse-guide, check-data, build-items, check-links, проверки, иконки
src/data/              маршрут V2, база предметов и JSON из гайда
src/services/          OSRS Wiki (Bucket API, статьи) и цены биржи
src/lib/               прогресс и перенос V1, «что сейчас», очки, квесты, опыт, поиск, масштаб
src/components/        карточка шага, этап, «сейчас», инспектор вики, поиск, переключатель режима
src/pages/             Путь, Навыки, Навык, Цели, Квесты, Справка, Настройки
tests/                 юнит-тесты
electron/              окно программы для ПК и мост к нему (preload)
vite.config.ts         сборка и генерация service worker (без workbox)
```

Зависимости: React, Vite, TypeScript, Vitest, для exe — Electron и electron-builder.
